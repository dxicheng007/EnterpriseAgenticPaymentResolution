# Source acquisition

Follow the [repository instructions](../../AGENTS.md), the [package boundaries](../AGENTS.md), and the frozen [evidence and coordinated snapshot contract](../../docs/superpowers/plans/2026-11-08-contract-freeze.md#f4--evidence-uploads-and-coordinated-snapshots).

- [Company A](src/company-a.ts) declares its read-only source contracts and constructs raw events. Preserve the frozen [source vocabulary](../../docs/superpowers/plans/2026-11-08-contract-freeze.md#f2--concrete-source-contracts-and-executable-dsl).
- [Visible fixture templates](src/canonical-fixtures.ts) generate public source inputs. The [operator generator](../../scripts/generate-fixtures.ts) writes protected evaluator v1 construction truth to separate, private roots. Existing output files require a fresh destination. Product imports must not reach protected truth, public comparison fixtures, or operator commands.
- [Uploads](src/uploads.ts) persist original associations and activity. [Dossiers](src/dossier.ts) read manifest capture state. Control owns source metadata in the [source migration](../../db/control/002_sources.sql).
- [Evidence extraction](../evidence/src/extract.ts), [locators](../evidence/src/locate.ts), and [byte storage](../evidence/src/store.ts) implement original-byte provenance. Preserve UTF-16 offsets and scoped associations. The [HTTP plugin](../../apps/control/src/routes/sources.ts) requires injected authorization.

Keep raw identity separate from approved customer scope. This package records source data and capture state. Compiler, finance and runtime own interpretation, money, and target writes.

[Company B](src/company-b.ts) decodes the fixed CSV envelope and declares independent file, receipt, and semantic streams. [Manifest services](src/manifest.ts) serve pinned captures and [change pages](src/change-feed.ts). [Scenario administration](src/scenario-admin.ts) is a separate operator-only import that requires its own token and explicit enablement. Keep it out of product tools.

[Source coverage](src/source-coverage.ts) reads one complete captured aggregate and its original associations to explain cited source identities. Keep the supported identity grammar separate from candidate and financial interpretation.

[Discovery capture reads](src/discovery-reads.ts) return validated capture binding, exact observed seller/account tuples and complete citation membership without writes or grants. They select the requested manifest, validate original bytes and stored members/citations, and recheck selected rows after external I/O. Valid events without a seller remain captured and cited but cannot contribute an invented seller/account tuple. Follow the [capture handoff](../../docs/progress/2026-11-08/handoffs/b-discovery-capture-read.md) and run `npm run test:integration -- tests/integration/discovery-capture-read.test.ts tests/integration/v1-manifests.test.ts tests/integration/v1-evidence.test.ts`. Lifecycle must separately authorize the caller and recheck bound immutable facts inside its creation transaction.

[Discovery source tools](src/discovery-tools.ts) prepares exact pinned contracts, records, search hits and bounded citation excerpts using original-verified detached capture data. File evidence with unknown account coverage stays inaccessible to account-only grants. Every CSV query event requires a reproducible existing captured batch-row citation before coverage filtering; missing originals fail closed. Keep the existing facts-only discovery reader output unchanged. Follow [D0/D1/D2 ownership](../../docs/progress/2026-11-08/handoffs/b-discovery-evidence-implementation-handoffs.md) and [reviewed D1 correction](../../docs/progress/2026-11-08/reviews/b-discovery-source-tools-fix-review.md). Source preparation grants no lifecycle/financial authority; owner-transaction rechecks remain D2's responsibility.

[Current semantics](src/current-semantics.ts) reads the latest published manifest and validated subsequent semantic changes under the existing source lock. Numeric stream sequence orders revisions; opaque revision IDs do not. Governing changes remain distinct from scoped seller/account entries. The [private composition](../../apps/control/src/source-semantics-composition.ts) requires an explicitly installed source-read capability and allowlist. Follow the [AS handoff](../../docs/progress/2026-11-08/handoffs/b-source-semantics-handoff.md) and [review](../../docs/progress/2026-11-08/reviews/b-source-semantics-independent-review.md). This standalone producer is not mounted by default; A4/A5 own consumer comparisons and installation. Use isolated `tests/integration/source-semantics.test.ts` for changes.
