## Exact accepted API

Accepted orchestration proposal §6 and executable discovery-shapes freeze already define:

- GET `/api/discovery/runs/:runId/events/cursor` →200 `{cursor:string}`.
- GET `/api/discovery/runs/:runId/events?after=<cursor>` →SSE `event: activity`, `id:<encoded cursor at this event sequence>`, `data:<ActivityEvent>`.
- Cursor uses existing `DiscoveryCursorV1={v:1,runId,controlCursor}` and encode/decodeDiscoveryCursor helpers; canonical unpadded base64url, strict max1024-byte wire, matching run, safe integer, no extra keys, future400 CURSOR_INVALID; below floor409 RESYNC_REQUIRED. Explicit query wins over Last-Event-ID; omitted both means0. Reject unrecognized query parameters.

Use `readControlActivityWindow(db)` and `readControlActivityPage(db,{after,limit,runId})`. No reader changes. Page limit is1..1000; proposed transport implementation uses100. Page reader already captures coherent highWater/floor/lookahead and checks row sequence/run/stream. Current floor0 with no pruning. Preserve its nextAfter/hasMore: unfinished page advances to last returned event; exhausted page advances internally to highWater. Each emitted SSE ID is its exact event sequence, never page highWater. Advance scan nextAfter only after all returned events were sent. Disconnect partway must resume from last delivered ID, not internal scan. Empty scans may progress internally; comments are heartbeats, not events or synthetic checkpoints. Never emit runtime or another run's activity.

Initial validation failures before headers use no-store safe ApiError with request correlationId. After headers, storage/replay/session failure emits `event: resync_required` and closes; proposed data is minimal `{code:'RESYNC_REQUIRED'}` without raw error. Normal60-second transport retirement closes for reconnect from last delivered cursor; this is not session expiration. Clear poll/heartbeat timers and listeners on close/shutdown, handle backpressure with bounded queued output; do not buffer an unbounded activity history. Reauthorize through reviewer authorizer and readState before every page/poll and again after a backpressure drain before emitting the unsent remainder of a buffered page; a stale buffered page must not bypass current authorization. On rejection discard unsent data and close via the supported redacted path. Disconnect/abort cancels pending drain/poll work. Use injected timer/transport seams for deterministic tests.

## Truthful minimum monitor

Input is an explicitly selected/run-linked run ID; no invented list-runs endpoint or local fake run. Proposed navigation is a Discovery page with a run ID field/link and capability/setup message. Do not add start UI dependent on new source-selection product design in this increment. Existing source start route remains available only with configured injected client. Default local app shows model unavailable/start unavailable; no scripted fallback. A test-created durable run can be opened by URL/run ID and reloaded.

For a selected run, get cursor first, state second, connect third. State is authoritative; events invalidate/refetch it, not additive counters. Deduplicate `(stream,sequence)`, ignore stale state revisions, invalidate old requests when run changes. On resync repeat cursor→state→connect; never move ongoing replay to a separately fetched high-water. Bound rendered event list (proposed200 recent events) while retaining last delivered cursor and authoritative totals; label list as recent activity. Reconnect normal60-second retirements from last delivered cursor. On actual401 from the current transport generation, call existing clearCsrfToken before getLocalSession: its expiration listener invalidates sessionPromise, so a cached fulfilled session is not reused. Coalesce listener/bootstrap callers through existing session cache and permit at most one automatic refresh/resync attempt per recovery episode; a repeated401 or bootstrap failure stops with visible retry. A successful authenticated connection ends the episode. Reject stale old-generation401 callbacks so they cannot invalidate a newer session. Actual403 stops without refreshing/reconnecting. A post-header generic resync_required reacquires cursor/state; their real HTTP status drives this same policy. Abort and cancel old fetch reader on selection/unmount and prevent stale callbacks updating another run.

Render pinned binding, mode/modelId, run status, task roles/subjects/dependencies/status/attempt/tool-round counts, in-flight counts, safe diagnostics, model calls/tokens and unknownUsageCalls; cost unavailable remains explicit. Task succeeded does not mean connector built. No findings/proposal/tool-result links unless the corresponding real endpoint is independently implemented. Empty findings/proposals are honest; construction unavailable/blocker is visible. Raw activity only uses accepted summaries, no reasoning pane or transcript. Pause/resume uses existing strict expectedRevision and fresh idempotency key with CSRF through existing HTTP client; expose conflicts and refetch, never blindly replay a failed mutation. Paused state shows already in-flight work honestly. No activation/approval button.
