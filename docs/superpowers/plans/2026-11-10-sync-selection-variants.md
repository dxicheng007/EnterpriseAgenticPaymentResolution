## Review Focus

1. Extraction can lose cleanup or bypass the genuine proof/reviewer path: Task 1 must pass the four unchanged fixed cases, including post-composition failure and exact report/attestation readback; Tasks 2/3 repeat genuine variant cleanup.
2. A latest-source capture can replace an older approved baseline or duplicate its original prefix: Task 2 checks two immutable captures, byte-identical prefix, epoch/watermark order, separate proof pins and exact per-lane membership.
3. Full two-profile proof can accidentally expand reviewer grants or count bundled membership as authority: Task 3 checks the complete selecting catalog before/after real capture, not only absence of one target.
4. Shared USD text can be mistaken for applicable evidence: Task 3 requires one real shared citation independently supporting each distinct contract fact's currency and the actual full financial profile matrix.
5.
